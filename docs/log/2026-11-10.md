## 구현 3단계: RF 평가 완료, CNN 학습 시작
- 변형 테스트셋(9조건) 생성, 검출률: clean 0.818(삽화 포함) / dark_0.5 0.62 / dark_0.25 0.293 / dark_0.12 0.057 / clutter 0.744 / shift 0.779 / scale_small 0.808 / scale_large 0.661 / rot15 0.813.
- RF/DT × 특징 3종 평가 → `EXP-003`. 핵심: 어두운 조명의 RF 손실은 대부분 검출 실패, geom 특징이 가장 강함.
- Keras가 `keras.callbacks`에서 jax를 import하는데 jaxlib이 AVX 요구 → override로 jax/jaxlib 제외.
- CNN 속도 실측: 96×96 4단 컨브(32-64-96-128) 배치 64가 3~5초/step(AVX 없는 2코어, 다른 프로세스와 경쟁) → 25 epoch × 6 run 불가. **64×64, 채널 16-32-64-96**으로 축소 (CNN 서브에이전트 권장 96×96에서 후퇴; 이유: 연산량). 이는 CNN에 불리한 설정일 수 있어 한계로 기록.

## CNN 사전 점검 (1 시드, plain, 64×64)
- 첫 시도에서 val_acc가 정확히 0.100에 고정 → 원인 가설: BatchNorm 이동 통계(momentum 0.99)가 40 step/epoch에서 수렴 못 함. momentum 0.9로 수정해 val이 정상 변동(커밋 기록). 
- 40 epoch 시도: train acc 0.81, val acc ≈ 0.49, clean 테스트(사진) 0.503, dark_0.25 0.097, shift 0.376. → 소규모(클래스당 약 250장 학습) 데이터에서 처음부터 학습한 CNN은 과적합하고 clean 정확도 자체가 RF(geom, det-only 0.985)보다 크게 낮다.
- 함의: "환경 강건성"을 비교하려면 clean 정확도 격차를 분리해야 함 → 지표를 절대 정확도뿐 아니라 clean 대비 상대 하락(Accuracy Drop)으로 보고, 전이학습 변형(추가)과 CNN-aug를 함께 본다. 3시드 × plain/aug를 40 epoch로 실행 중.
