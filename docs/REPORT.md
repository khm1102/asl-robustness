# 최종 요약 (REPORT)

대상: ASL 정적 알파벳 10종(A,B,D,F,I,L,U,V,W,Y; 4,198장). MediaPipe 랜드마크 + RF vs 소형 CNN(plain/aug)의 환경 변화 강건성. 모든 수치는 `results/*.json`의 실제 실행 결과이며 근거 실험 문서를 병기한다. 평가는 그룹 분할 test 840장 중 **사진 부분집합 715장**.

## 핵심 결과
1. clean 정확도: RF geom(e2e) 0.942 (검출된 것만 0.985, 검출률 0.957) > RF norm 0.834 > CNN-plain 0.577 > CNN-aug 0.477 (EXP-003/004/005).
2. 어두움: RF는 모델 자체보다 **MediaPipe 검출 실패**로 하락(검출률 0.957→0.727→0.344→0.067; 검출된 것만 보면 0.961/0.863/0.722). CNN-plain은 dark_0.5에서 이미 0.110(무작위 0.10 수준)이며 대부분 `I`로 예측(혼동행렬). dark_0.5에서 CNN-plain 하락이 RF보다 22.3%p 크다(CI 17.9~26.5).
3. CNN-aug는 dark_0.5(0.110→0.318), clutter(0.199→0.374)를 개선하나 clean이 9.9%p 하락하고 절대 정확도는 모든 조건에서 RF geom보다 낮다. aug는 어둠/잡동사니를 학습에 포함 → 해당 조건은 미학습 변형이 아님.
4. 이동/크기: RF raw→norm 효과 큼(scale_small에서 +31.7%p), geom은 norm보다 전 조건 약 +10%p.
5. 데이터 분할 누수(H1)는 작다: 근접 중복 1.3%, RF 차 −0.7%p, CNN 차는 노이즈 수준(EXP-006).
