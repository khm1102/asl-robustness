# 문서 인덱스

모든 가설·추론·분석·검증·구현은 여기에 남긴다. 규칙: **주장 → 근거(커밋/결과 파일/로그) 링크** 형태로 쓰고, 모르면 `[미확인]`으로 둔다.

| 문서 | 내용 |
|---|---|
| `hypotheses.md` | 가설 대장. 상태(제안/검증중/지지/기각/보류)와 기각 조건, 근거 링크 |
| `decisions/NNNN-*.md` | 설계 결정 기록(ADR): 맥락 → 선택지 → 결정 → 결과 |
| `experiments/EXP-NNN-*.md` | 실험 기록: 목적, 가설, 설정(시드·커밋), 결과 표, 해석, 한계 |
| `log/YYYY-MM-DD.md` | 시간순 작업 일지(무엇을 했고 왜, 막힌 점, 서브에이전트 토론 요약) |
| `proposal.pdf` | 원본 기획안 |

## 추적 규칙
1. 가설은 ID(H1…)를 갖고, 실험은 반드시 검증하는 가설 ID를 적는다.
2. 실험 문서에는 git 커밋 해시, 시드, 데이터 버전을 적는다.
3. 결과가 가설과 달라도 삭제하지 않고 상태만 바꾸고 이유를 적는다.
4. 서브에이전트 의견은 `log/`에 요약하고, 채택/기각한 이유를 `decisions/`에 남긴다.
