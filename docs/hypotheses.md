## 필수 통제/ablation
- CNN-plain vs CNN-aug (공정성)
- RF 특징 3종: 원시 / 손목 기준 정규화 / 정규화+거리·각도
- 검출 실패 처리 2종: end-to-end(실패=오답) vs detected-only(검출 성공만)
- 분할 2종: 무작위 vs 중복 제거+그룹
- 3 seeds, 부트스트랩 CI, 같은 테스트 샘플에 대한 McNemar/paired bootstrap
