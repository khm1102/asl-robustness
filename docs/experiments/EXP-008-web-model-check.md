# EXP-008. 웹 데모용 저장 모델 vs 실험 결과 일치 확인

- 목적: 웹 라이브 탭이 쓰는 재학습 모델(`aslrob.train_final`, 시드 0)이 보고서 수치와 같은 수준인지 확인. 코드 `aslrob.web.check_models`, 결과 `results/web_model_check.json`.
- 설정: 그룹 분할 test 사진 715장, 9개 조건, 변형 이미지/랜드마크는 실험 때 저장한 값 그대로.

| 조건 | RF geom e2e | CNN-plain 저장모델 (실험 3시드 평균 ± sd) | CNN-aug 저장모델 (실험 평균 ± sd) |
|---|---|---|---|
| clean | 0.943 | 0.503 (0.577 ± 0.055) | 0.421 (0.477 ± 0.066) |
| dark_0.5 | 0.699 | 0.120 (0.110 ± 0.007) | 0.172 (0.318 ± 0.107) |
| dark_0.25 | 0.297 | 0.097 (0.099 ± 0.003) | 0.103 (0.147 ± 0.036) |
| dark_0.12 | 0.048 | 0.099 (0.103 ± 0.003) | 0.108 (0.096 ± 0.008) |
| clutter | 0.825 | 0.173 (0.199 ± 0.018) | 0.313 (0.374 ± 0.063) |
| shift | 0.857 | 0.376 (0.429 ± 0.042) | 0.357 (0.423 ± 0.055) |
| scale_small | 0.938 | 0.224 (0.247 ± 0.017) | 0.274 (0.284 ± 0.027) |
| scale_large | 0.699 | 0.411 (0.439 ± 0.020) | 0.297 (0.386 ± 0.069) |
| rot15 | 0.934 | 0.490 (0.559 ± 0.057) | 0.401 (0.460 ± 0.059) |

## 해석
- RF는 실험과 사실상 동일(0.943 vs 0.942 등; 시드 0이며 RF 시드 간 차이가 작음).
- CNN 저장 모델은 거의 모든 조건에서 실험 3시드 평균보다 **약간 낮다**(plain 0.5~7%p, aug 최대 14.6%p(dark_0.5)). 대부분 시드 sd(0.02~0.11)의 1.5배 이내. 3시드 평균이 아니라 한 시드의 결과이므로 설명 가능하지만, 학습 난수(증강/배치 순서)가 실험 때와 달라 같은 가중치가 아님 `[미확인: 이 시드가 하위 시드인지 우연인지 구분 안 함]`.
- 순서 관계(RF ≫ CNN-aug ≥ CNN-plain는 어두움 0.5, clutter 등)는 유지. 단 dark_0.5에서 aug(0.172)가 plain(0.120)보다 앞서는 폭이 실험(0.318 vs 0.110)보다 작다 → **웹 라이브에서 CNN-aug의 어둠 개선이 보고서보다 작게 보일 수 있음.**
- 웹 ‘테스트셋 둘러보기’ 탭은 이 모델이 아니라 실험 때 저장한 시드 0 예측을 쓴다(보고서와 같은 모델 출력). 라이브 탭만 재학습 모델.
