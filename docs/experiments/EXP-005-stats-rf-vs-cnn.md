# EXP-005. RF vs CNN 쌍체 통계 (H2, H3, H5, H6)

- 코드: `aslrob.stats` (`results/stats.json`, `results/figs/confusion_{rf_geom,cnn_plain,cnn_aug}.png`), 표: `aslrob.table`
- 대상: 그룹 분할 test의 **사진 부분집합**(같은 샘플, 조건별 같은 `idx`), 시드 3 평균 정답률(샘플별 0~1).
- 방법: ① paired bootstrap(샘플 재표집 2000회, 95% 퍼센타일 CI) — 정확도 차, 그리고 Accuracy Drop 차 `(clean−cond)_A − (clean−cond)_B`. ② McNemar(정확 이항검정) — 시드 3개 중 ≥2개 정답을 '다수결 정답'으로 사용.
- 비교는 **end-to-end 기준만** 수행(RF 검출 실패=오답). det-only 비교는 `[미수행]`.
- 한계: 부트스트랩은 샘플만 재표집하고 시드 변동은 평균으로 흡수 → CI가 시드 분산(CNN sd 0.05~0.11)을 반영하지 않아 좁게 나옴. 여러 조건·쌍을 보정 없이 검정(다중비교 보정 안 함). 같은 촬영자의 샘플이 test에 여럿(그룹 내 상관) → 독립 가정이 과대평가.
- McNemar(다수결)와 bootstrap(시드 평균)은 지표가 달라 결과가 엇갈릴 수 있음(예: cnn_aug−rf_geom|dark_0.12 bootstrap +0.048 CI>0인데 McNemar p=0.62). 둘 다 그대로 `stats.json`에 기록.

## 정확도 차 (CNN − RF geom)
- 모든 조건에서 CNN-plain·aug 모두 RF geom보다 낮음(예: clean plain −36.6%p [−39.5, −33.6], aug −46.5%p). 유일한 예외 dark_0.12: RF가 검출률 6.7%로 사실상 전멸해 CNN(무작위 0.10 수준)이 +5.5%p(plain) 높음.
- aug − plain: dark_0.5 +20.7%p [18.1, 23.6], clutter +17.5%p [14.5, 20.5], scale_small +3.7%p, **clean −9.9%p [−12.7, −7.0]**, rot15 −9.9%p, scale_large −5.4%p, shift CI가 0 포함(−0.6%p).
- RF geom − norm: 전 조건에서 약 +10%p(dark_0.12 제외) → 거리·각도 특징이 정규화 좌표보다 우수(H6). RF norm − raw: shift +16.2%p, scale_small +31.7%p, clean/rot15는 CI가 0 포함.

## 혼동행렬 관찰
- CNN-plain dark_0.5: 거의 모든 클래스를 `I`로 예측(열 하나로 몰림). 변형 분포 이동으로 인한 붕괴로 보임 — 원인 확정은 `[미확인]`.
- clean에서 CNN 혼동은 F–I, V–W, U 주변 등 모양이 비슷한 쌍에 분산(그림 참조, 정량화 안 함).

## 가설 판정 (근거 = 위 수치)
- **H2 부분 지지**: dark_0.5에서는 CNN-plain 하락이 RF보다 22.3%p 크다(CI 0 제외). 그러나 dark_0.25, 0.12에서는 RF e2e 하락이 더 크다(검출 붕괴 + CNN은 이미 바닥 0.10이라 하락폭이 구조적으로 작음). 기각 조건(CNN 하락 ≤ RF)은 어두운 조건 일부에서 충족 → 전체 지지 아님.
- **H3 부분 기각**: aug는 dark_0.5와 clutter 격차를 크게 좁힘(drop 기준 clutter에서 RF와 구분 안 됨: −1.3%p, CI 0 포함 → 기각 조건 충족). 단 절대 정확도는 RF보다 한참 낮고(clutter 0.374 vs 0.826) clean 자체가 plain보다 9.9%p 낮다. aug 학습에는 어둠(0.1~1.0)·잡동사니가 이미 포함(`cnn_exp.augment_batch`) → 해당 변형은 '미학습 변형'이 아님(공정성 주의).
- **H5**: CNN 쪽 비교 결과 — 검출 실패를 오답 처리해도 RF geom e2e가 CNN보다 높은 조건이 dark_0.12를 제외한 전부. 'RF 우위가 사라지는' 조건은 dark_0.12 하나뿐(RF e2e 0.048 vs CNN 0.10). 부분 지지.
- **H6**: geom > norm 지지(CI>0), norm > raw는 이동/크기 변형에서만 지지.
- 해석 주의: CNN이 clean에서 이미 크게 낮은 것은 소규모 데이터·64×64·소형 모델 영향일 수 있어 '구조적 약점'과 분리되지 않음 `[미확인]`.
