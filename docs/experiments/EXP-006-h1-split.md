# EXP-006. H1: 무작위 분할 vs 중복 제거+그룹 분할

- 코드: `aslrob.h1_split`, 결과: `results/h1_split.json`. 각 분할의 **자체 test**(원본 clean 이미지, 사진 부분집합)로 평가. 학습/검증/테스트 크기는 두 분할 모두 2518/840/840.
- 사전 측정(EXP-001, `prepare_stats.json`): 근접 중복 군집 23개(56장, 1.3%), 무작위 분할 test 중 train과 군집을 공유하는 비율 1.67%.
- 모델: RF geom(300 트리, 시드 3, e2e: 검출 실패=오답), CNN-plain(EXP-004와 동일 설정, 시드 3).

| 분할 | 사진 n | RF geom e2e | RF det-only | CNN-plain (3 시드) |
|---|---|---|---|---|
| group | 715 | 0.942 / 0.941 / 0.943 | 0.985 | 0.499, 0.594, 0.635 (평균 0.576) |
| random | 695 | 0.935 ×3 (시드 간 동일) | 0.982 | 0.669, 0.583, 0.616 (평균 0.623) |

## 해석 (잠정)
- 누수가 1.7% 수준이라 예상대로 효과가 작다. RF: random이 오히려 0.7%p 낮음 → H1의 "무작위가 더 높다"는 방향도 성립하지 않음(기각 조건 <1%p).
- CNN: random이 +4.7%p지만 CNN 시드 간 범위가 0.499~0.635로 넓어(시드 간 최대 13.6%p) 차이가 노이즈 안에 있다. 또한 두 분할의 test 샘플이 달라(715 vs 695장) 쌍체 비교가 아님. 따라서 "CNN이 근접 중복을 외운다"는 근거로 쓸 수 없다 `[미확인: 누수 샘플만 따로 정확도 비교하지 않음]`.
- 한계: 분할을 한 번만 사용(분할 시드 1개). 다른 분할 시드로 반복하면 결론이 달라질 수 있음 `[미수행]`.
- 부수 관찰: 같은 설정(group, plain)의 CNN 시드 3개가 EXP-004(0.577)와 거의 같은 값(0.576)으로 재현됨(같은 시드·같은 코드, 재현성 점검).
