# EXP-002. 깨끗한 이미지에서 MediaPipe 검출률과 실패 원인

- 검증 대상: H5(검출 실패), 데이터 품질
- 코드: `aslrob.landmarks`, `aslrob.tags`; 설정 conf=0.3, max_num_hands=1, 256×256 입력, MediaPipe 0.10.14
- 데이터: 10개 알파벳 4,198장 (`results/` 에 raw 결과 파일은 두지 않고 `data/processed/lm_clean.npz`에 캐시, git 제외)

## 결과 (직접 실행)
- 전체 검출률: **80.5%** (3,379/4,198). 알파벳별 76.7%(I) ~ 84.5%(L).
- 실패 24장을 무작위 시각 확인: 흑백 삽화 약 15~16장, 손이 프레임에 잘린 이미지 약 3~4장, 과노출/단색 배경 몇 장. (육안 집계라 근사)
- 삽화 자동 태그(평균 채도<12 & 흰 픽셀 비율>0.5)로 분류: 삽화 644장(15.3%), 사진 3,554장.
  - **검출률: 삽화 2.9%, 사진 94.5%**.

## 해석
- 검출 실패의 대부분은 "환경 변화"가 아니라 **데이터셋에 섞인 손 삽화**다. 삽화가 15%를 차지하므로, 이를 포함해 end-to-end 정확도를 내면 RF는 상한이 약 80%로 고정된다 — CNN과의 비교가 불공정.
- 결정: **주 비교는 사진 부분집합(삽화 제외)**, 삽화 포함 결과는 보조(검출 실패 포함 end-to-end)로 보고. → `decisions/0005`.
- 한계: 삽화 태그는 휴리스틱(오분류 가능) `[미확인: 태그 정확도 별도 검증 안 함]`. 사진 중 손이 잘린 이미지는 포함된 채.
