# EXP-003. 손 관절 + RF/DT 환경 변화 강건성 (사진 부분집합, 3 시드 평균)

- 검증 대상: H2(RF 측 기준선), H4, H5, H6
- 코드: `aslrob.rf_exp`, `aslrob.testsets`, `aslrob.perturb`, `aslrob.features`; 결과: `results/rf_results_group.json`

- 학습: 그룹 분할 train 2518장 중 검출 성공 2006장. RF 300 트리, DT 기본값, 시드 0~2. 테스트: 그룹 분할 test 840장 중 사진(삽화 제외).
- 표기: e2e = 검출 실패를 오답 처리한 정확도, det-only = 검출 성공 샘플만, det = 검출률.

## 관찰 (표에서 직접 읽은 값)
1. **검출률이 지배한다 (H5 지지).** 어두움 0.5/0.25/0.12에서 검출률은 0.957 → 0.727 / 0.344 / 0.067. geom RF 기준 det-only는 0.985 → 0.961 / 0.863 / 0.722로 완만하게 떨어지는데 e2e는 0.942 → 0.699 / 0.297 / 0.048로 급락. 즉 어두운 조명에서 RF 계열의 손실 대부분은 분류기가 아니라 **MediaPipe 검출 실패**.
2. **위치/크기 정규화 효과 (H4 부분 지지).** raw RF det-only: clean 0.868 → shift 0.646, scale_small 0.544. norm RF: 0.872 → 0.824, 0.878. norm으로 shift 하락이 22.2%p → 4.8%p. 다만 norm도 shift에서 완전 0은 아님(기각 조건 ‘>3%p’ 충족 → **H4의 “거의 0” 부분은 기각**): 이동 시 평균색 패딩이 생겨 랜드마크 품질이 변했을 가능성 `[미확인]`.
3. **특징 선택이 가장 큰 효과 (H6 부분).** 같은 RF에서 clean det-only: raw 0.868, norm 0.872, geom 0.985. 좌표 그대로는 축 정렬 트리가 약하고 거리·각도 특징이 훨씬 유리. 이 비교는 "RF가 좌표를 쓴다"가 아니라 "특징 설계"의 효과라는 점을 CNN 비교 때 구분해야 함.
4. **RF vs DT (H6).** clean geom det-only: RF 0.985, DT 0.962 (차 2.3%p). 단일 트리가 의외로 강함 → 특징이 정보를 거의 다 담고 있음. norm에서 RF가 DT보다 약 14%p, raw에서 약 17%p 우위.
5. **큰 확대(scale_large)**는 손이 잘려 검출률 0.769, det-only도 하락(geom 0.909).
6. **rot15**: norm/raw/geom 모두 거의 영향 없음 (z 포함 3D 정규화는 회전에 불변이 아닌데도 15° 정도는 트리가 흡수) `[가설: MediaPipe가 회전된 손의 랜드마크를 회전 보정해 반환]`.

## 한계
- 변형은 합성. 어둠은 선형 감광+가우시안 노이즈이며 실제 저조도 카메라 파이프라인이 아님.
- 검출 임계값 conf=0.3 하나만 시험(0.1~0.5 민감도 미실시).
- 테스트 사진 약 700장, 시드 3개: 신뢰구간 미계산(CI/McNemar는 CNN 결과 후 추가 예정).
- det-only는 쉬운 샘플만 남는 선택 편향이 있어 변형 간 단순 비교에 주의(검출 가능한 샘플 집합이 조건마다 다름).
