# EXP-006. H1: 무작위 분할 vs 그룹(중복 제거) 분할

- 검증 대상: H1. 코드 `aslrob.h1_split`, 결과 `results/h1_split.json`.
- 설정: 각 분할의 자체 test(원본 clean, 변형 없음)의 사진 부분집합으로 평가. RF(geom, 검출 성공 샘플만 학습, e2e), CNN-plain(64×64, 40 epoch, 시드 3).
- 주의: 두 분할은 test 샘플 집합이 다르다(사진 715장 vs 695장). 같은 샘플끼리의 paired 비교가 아니다.

| 분할 | RF e2e | RF det-only | CNN-plain (시드별) | CNN 평균 ± sd |
|---|---|---|---|---|
| 그룹 | 0.942 | 0.985 | 0.499 / 0.594 / 0.635 | 0.576 ± 0.057 |
| 무작위 | 0.935 | 0.982 | 0.669 / 0.583 / 0.616 | 0.623 ± 0.036 |
| 무작위 − 그룹 | −0.7%p | −0.3%p | | +4.6%p |

## 해석
- RF: 무작위 분할이 오히려 약간 낮다(−0.7%p). 누수 징후 없음. 기각 조건(차 <1%p) 충족.
- CNN: 무작위가 +4.6%p 높지만 시드 간 sd(0.04~0.06)와 같은 크기이고 시드 3개뿐이라 **누수 효과인지 시드/표본 차이인지 구분 못 함** `[미확인]`.
- EXP-001에서 중복 군집이 전체의 약 1.3%, 무작위 분할 test 중 train에 같은 군집이 있는 비율이 1.7%였던 것과 방향이 일치: **이 데이터셋에서 근접 중복 누수는 작다.**
- 한계: 촬영자/세션 누수는 ID가 없어 측정하지 못함. 그룹 분할도 dHash 군집 기준일 뿐 촬영자 분리가 아니다. 반전 중복(좌우 반전)은 해시가 잡지 못함.
- 판정: **H1 기각(RF) / 판정 불가(CNN)** → 전체로는 "중복 누수는 결론을 뒤집을 만큼 크지 않다"까지만 주장.
