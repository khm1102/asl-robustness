# EXP-007. MediaPipe 검출 임계값(min_detection_confidence) 민감도

- 검증 대상: H5 보강("검출 실패가 RF 손실의 주원인"이 임계값 선택의 산물인가). 코드 `aslrob.conf_sens`, 결과 `results/conf_sens.json`.
- 설정: 그룹 분할 test 사진 부분집합(715장), 변형은 testsets와 동일 시드. RF(geom, 시드 0 하나)는 conf=0.3 의 clean 랜드마크로 학습 → 평가에서만 conf를 바꿈. 
- 주의: 시드 1개, 표본 715, CI 미계산.

## 해석
- 임계값을 0.5→0.1로 낮추면 검출률이 모든 조건에서 오르고(dark_0.25: 0.301→0.425) e2e도 오른다. 낮은 임계값이 e2e에 유리, det-only는 더 어려운 샘플이 들어와 약간 떨어짐(dark_0.5: 0.979→0.942) → 선택 편향의 크기를 보여 줌.
- 그러나 **가장 낮은 임계값(0.1)에서도 어두운 조건의 검출 붕괴는 해소되지 않는다**: dark_0.25 e2e 0.350 (clean 0.959 대비 −60.9%p), dark_0.12 0.083. H5의 결론(검출 단계가 RF의 병목)은 임계값 선택에 의존하지 않는다.
- 기획안 설정이 더 불리하지 않도록 주 결과(conf=0.3)와 병행 보고. 0.1을 쓰면 dark_0.5에서 RF e2e가 0.699→0.724(+2.5%p)로 CNN과의 격차가 더 벌어진다.
- 한계: 임계값 외에 `model_complexity`, 이미지 전처리(밝기 보정 후 검출) 같은 완화책은 시험하지 않음 → 어두운 조건에서 검출 전 밝기 보정을 하면 RF 손실이 크게 줄 수 있음 `[미확인, 후속]`.
