# 0003. 실험 설계 (서브에이전트 3종 토론 결과 반영)

- 상태: 채택(코드 구현 중 수정 가능)
- 토론 참여: 적대적 리뷰어 / RF 방법론 / CNN 방법론. 세 에이전트 모두 **코드를 실행하지 않고** 지식 기반으로 답했으므로, 수치(에포크 시간, 임계값 등)는 가설이며 실측으로 대체한다.

## 채택
1. **누수 방지**: pHash로 근접 중복 군집화 → 군집 단위 StratifiedGroupKFold/분할. 무작위 분할 정확도와 병행 보고(H1).
2. **CNN 공정 대조군**: CNN-plain, CNN-aug 둘 다 (H2/H3). 입력 96×96 RGB, 작은 CNN(Conv 32-64-96 + BN + GAP). 학습 시간은 실측 후 64/128 조정.
3. **RF 특징 3종 비교**(H4/H6), 검출 실패는 end-to-end와 detected-only 둘 다 보고(H5).
4. **통계**: 3 seed, 테스트 부트스트랩 CI, 모델 간 paired 비교.
5. **알파벳 부분집합**: 정적이고 일부 혼동되는 쌍을 포함한 10개. `A B D F I L U V W Y` (U/V 혼동쌍 포함, J/Z 제외).
6. **메모리**: uint8 npy memmap 캐시(96×96, 및 MediaPipe용 256).

## 보류/수정한 의견
- 전이학습(MobileNetV3)은 "처음부터 학습하는 CNN"이라는 기획안과 달라 **추가 변형으로만**, 시간이 남을 때.
- 배경 교체 변형은 마스크 품질에 좌우됨(리뷰 결함 2) → 마스크로 손을 먼저 지우지 않도록, 배경 변형은 "가장자리 영역 노이즈/패턴 오버레이"와 "손 마스크가 있는 경우만 교체" 중 구현 가능한 것부터. [미확인: 데이터셋에 마스크 없음 → MediaPipe 세그먼트 대신 단순 오버레이로 시작]
- 직접 촬영 테스트셋은 팀원이 만들 예정이라 현재 없음. 합성 변형 결과만 보고하고, 실촬영은 외부 타당성 검증 슬롯으로 비워 둠.
