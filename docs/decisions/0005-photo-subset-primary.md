# 0005. 주 비교는 사진 부분집합, 삽화 포함은 보조

- 상태: 채택
- 맥락: EXP-002 — 삽화는 15%이며 MediaPipe 검출률 2.9%. 이를 end-to-end에 섞으면 RF 정확도가 구조적으로 낮아져 환경 강건성 비교가 아니라 "삽화 처리 능력" 비교가 됨.
- 선택지: (a) 전체 포함 end-to-end만, (b) 삽화 제거, (c) 둘 다 보고.
- 결정: (c). 주 결과 = 사진(삽화 태그=False). 보조 결과 = 전체. 두 경우 모두 검출률을 함께 표기. 변형 실험의 검출 실패는 end-to-end(실패=오답)와 detected-only 모두 보고(H5).
- 분할은 전체 데이터 기준 그룹 분할을 유지하고 평가 시 마스크로 부분집합을 고른다(학습 데이터 크기를 동일하게 유지하기 위해 CNN은 사진만으로도 학습하는 변형을 ablation으로).
