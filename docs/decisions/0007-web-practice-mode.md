# 0007. 웹 라이브 탭에 ‘따라하기’(연습) 모드 추가

- 상태: 채택
- 요구(사용자): 수어를 모를 수 있으니 영단어를 텍스트로 먼저 보여 주고 올바른 수어를 보여 줘서 따라 하게.
- 결정
  1. 참고 그림은 Wikimedia Commons ‘Sign language X.svg’(퍼블릭 도메인 표기)를 사용. 데이터셋의 손 그림은 **쓰지 않음** — 직접 확인한 결과 회전·왜곡 증강이 섞여 있고 출처/라이선스가 불명(`decisions/0002`).
  2. 참고 그림 10장을 시각 확인: A·B·D·I·L·U·V·W·Y는 표준 지문자와 일치. F는 엄지-검지 원 모양이 그림에서 작게 보여 약간 불명확 `[미확인: 원어민/교재 대조 안 함]`.
  3. 단어는 학습 알파벳 10개만으로 구성 가능한 것(FLY BUY WAY DAY LAB LID BAD FAIL WILD DIAL AVID FLAW DUAL VIA)을 사용, 코드에서 부분집합 확인.
  4. 성공 판정은 선택한 모델이 연속 5프레임(약 0.7초@7FPS) 정답일 때. 판정 모델을 바꿀 수 있어, 같은 동작에서 모델별로 통과 속도가 어떻게 다른지 체험적으로 비교 가능.
  5. 연습 종료 시 글자별 모델 정답 프레임 비율을 표시. 성공 직전 프레임만 집계하는 선택 편향이 있어 통계 결과로 해석하지 않음(화면에 명시).
- 관찰(부수): 데이터셋의 ‘사진’ 중에도 손이 크게 회전된 이미지가 많아(예: I 클래스 사진 8장 중 다수가 기울어짐) 데이터에 회전 증강이 이미 포함된 것으로 보임 `[미확인: 원본 데이터셋 설명 없음]`. 이는 `rot15`가 ‘미학습 변형’이라는 EXP-004/005의 가정에 영향을 줄 수 있어 REPORT 한계에 추가.
